# phishing-url-detector

ML-powered phishing URL detection and classification.

## Dataset

This project uses the **PhiUSIIL Phishing URL (Website)** dataset from the
UCI Machine Learning Repository.

[UCI Machine Learning Repository – PhiUSIIL Phishing URL Dataset](https://archive-beta.ics.uci.edu/dataset/967/phiusiil%2Bphishing%2Burl%2Bdataset)

> Prasad, A., & Chandra, S. (2024). _PhiUSIIL Phishing URL (Website) [Dataset]._
> UCI Machine Learning Repository.
> https://doi.org/10.1016/j.cose.2023.103545
